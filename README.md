## 关于本书

本项目旨在把孙宇晨两期访谈里能动手的观点，做成一本照着就能做的 AI 入门教程。

- 两期访谈都转成了带时间戳的全文，每个观点都能点回视频里的原话。
- 每篇教程配一段写给 AI 的话，复制给 Agent 它就照着做，也有一步步的手动做法。
- 示例结果都是照提示词真跑出来的，每个工具都有国内能直接用的版本。

若本书对你有帮助，请在页面右上角点个 Star :star: 支持一下，谢谢！
