# 03 看空也不急着做空

> 「虽然我看空，还没做空，啊没做空。」
> 「嗯持仓也在，但是我是，因为我自己观点可以有变化，我是微微看空。」
>
> 孙宇晨，[00:37:24](https://www.youtube.com/watch?v=o9Jn__LGGI4&t=2244s)

纳指他算重仓，中线微微看空，但没做空，持仓也在。以太坊他在 3600 到 4000 美元附近看到二顶，减了八九成。BTC 当底仓，没有减。他拿英伟达打比方，底仓除非彻底不看好 AI 了，否则一份都不减。看法是看法，仓位是仓位，他分得很清楚。

这一篇帮你建一本判断日志，把"我怎么看"和"我手里拿着什么"分开记，过一段时间再回来对答案。只管记录和复盘，不管买什么卖什么。

## 怎么做

1. 新建一个文件，每条判断写一行。写清楚看的是什么，看多还是看空，有多确定，为什么这么看。
2. 同一行再写一句，看到什么情况就说明我错了。
3. 另起一个表记仓位，现在拿了多少，是底仓还是进攻仓。底仓是看法彻底变了才动的，进攻仓是跟着判断加减的。
4. 判断变了就写新的一行，旧的不删，标上改的日期和原因。
5. 隔一段时间把日志交给 AI，让它对照后来的走势，看看哪些判断对了，哪些是运气，哪些时候嘴上和手上不一样。

## 让 AI 帮你搭

```
帮我建一本判断日志。
1. 建一个 判断日志.md，每行记：日期、看的是什么、看多还是看空、确定程度 1-5、理由、什么情况说明我错了。
2. 建一个 仓位.md，记我每个仓位是底仓还是进攻仓。
3. 我说「记一条」，你就问我这几项，补进去。
4. 我说「复盘」，你就读日志和仓位，找出看法和仓位对不上的地方、改过的判断，还有我写的"说明我错了"的情况有没有出现。只说事实，不给买卖建议。
```
