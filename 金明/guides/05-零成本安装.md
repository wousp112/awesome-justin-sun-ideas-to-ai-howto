# 05 零成本安装

> 「孙学呢，最合适的一点就是零成本安装，安装系统。就跟AI一样，这个skill就直接蒸馏，直接蒸馏就零成本安装，零成本安装。」
>
> 孙宇晨，[00:25:41](https://www.youtube.com/watch?v=o9Jn__LGGI4&t=1541s)

孙宇晨拿 AI 的 skill 比喻孙学。skill 是一份写给 AI 的说明，把一套方法提炼进去，大家常说「蒸馏」，别人的 AI 装上就能照着用。这个仓库的 [AGENT.md](../../AGENT.md) 就是这么来的，我们把两期访谈蒸馏成一份说明，复制给你的 AI，它就能照着访谈的思路帮你出主意。

这一篇教你把一个你认同的方法，或者你自己做事的方法，蒸馏成一个 AI 能装的 skill。

## 怎么做

1. 找到原材料，访谈全文、书摘、你自己的笔记都行。越接近原话越好。
2. 让 AI 读完，提炼出这个方法的几条核心判断，每条附上原话出处。
3. 再让它写清楚遇到具体问题时怎么用这些判断，先问什么，再比较什么，最后给出什么。
4. 写成一个 SKILL.md 或 AGENT.md，开头一句话说明这是什么、什么时候用。SKILL.md 是 Claude Code、Codex 这类工具认的技能文件，装好后 AI 会在用得上的时候自己调出来。AGENT.md 是一份说明，复制给任何 AI 都能用。这个仓库两样都有，装法见 [首页](../../README.md)。
5. 开一个新对话，拿一个真实问题试一次。回答里用上了你写的那几条判断，就说明读到了。完全没用上，先检查文件有没有装对位置，再看是不是写得太散。
6. 改到满意，就可以发给朋友，或者开源出来。

## 让 AI 帮你搭

```
帮我把一套方法蒸馏成 skill。
1. 读我放在 素材/ 里的原材料。
2. 提炼 5-10 条核心判断，每条附上原文出处。
3. 写清楚遇到问题时怎么用：先问用户什么，再怎么比较，最后输出什么。
4. 写成 skills/【名字】/SKILL.md，开头写明这是什么、什么时候用。
5. 帮我准备 3 个测试问题。我在新对话里试完，把结果发给你，你再改。
```
