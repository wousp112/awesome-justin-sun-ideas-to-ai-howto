# 01 从不关注到密切关注

> 「我们也要从就是完全不关注，改为密切关注，对吧，密切关注了。因为现在这个 AI 啊、数学啊发展的速度都很快，所以我觉得是进入一个密切关注的时代。」
>
> 孙宇晨，[00:13:36](https://www.youtube.com/watch?v=o9Jn__LGGI4&t=816s)

孙宇晨没有急着卖 BTC，先把币存好，然后盯着 AI 和数学的进展。他说的 Q-Day，指量子计算机能破解现在常用加密算法的那一天。他原来估计还有两年，看到 OpenAI 在数学上的进展后，觉得从访谈时算起，一年到一年半就得考虑了。

Q-Day 这种事，现在不急，真来了损失会很大。对付这类事，可以搭一个观察哨。它不会自动报警，靠你订阅几个一手来源，隔一阵让 AI 帮你汇总。下面拿 Q-Day 举例，你关心的是别的事，照着换掉就行。

## 做完是这样

示例盯的风险是「AI 会不会影响我的运营岗位」，个人经历是编的。AI 写的第一期观察哨：

```
# 观察哨｜2026年10月31日

盯什么：AI 改变互联网运营工作，可能影响我的岗位或收入。

离行动线有多远：尚未触发。现在只有试用安排，没有正式通知
说岗位取消或降薪。

行动线：收到书面通知确认岗位取消或降薪，7 天内更新简历、
整理三项能公开的工作成果。

接下来盯四个信号：
1. 公司安排：试用转成正式流程，出现岗位或薪资调整。
2. 招聘要求：上海同类运营岗位反复要求会用 AI。
3. 工具能力：AI 开始覆盖自己常做的文案、数据整理。
4. 就业变化：新的研究或政策。
```

## 让 AI 帮你搭

```
帮我给一件长期风险搭一个观察哨。
1. 先问我要盯什么事，它真发生了对我有什么影响。
2. 帮我列出 3-5 个说明它在靠近的信号，每个信号推荐 1-2 个一手来源，给出 RSS 地址或订阅方式。
3. 帮我写一条行动线：看到什么，我就做什么。
4. 我把收藏的内容发给你，你就写一页 观察哨/【日期】.md：有什么新进展、离行动线还有多远、我现在要不要动。
```

## 一步步来

1. 写下你要盯的那件事，再写一句它真发生了对你有什么影响。比如你手里有币，Q-Day 来了，老地址里的币可能被盗。
2. 想一想哪些信号说明它在靠近。拿 Q-Day 来说，可以看量子计算机的规模、破解算法的新论文，还有比特币社区的抗量子提案。
3. 每个信号找一两个一手来源，论文网站、官方博客和开发者邮件列表都算，订阅进 RSS 阅读器。arXiv 的量子计算分类可以直接订阅 `https://rss.arxiv.org/rss/quant-ph`，其他来源找不到订阅地址，就让 AI 帮你查。订阅好以后，隔几天看一眼有没有新文章进来。
4. 写一条行动线，看到什么就动手。比如有人公开演示用量子计算机破解了一把短一些的密钥，你就把币挪进新地址，做法见 [02](02-币进掩体.md)。信号、来源和行动线写在一页里，[模板/观察哨.md](../../模板/观察哨.md) 有现成的。
5. 收藏攒到一定数量，交给 AI 整理成一页简报，看看离你写的那条线还有多远。简报要是说不清还差多远，问题通常出在行动线写得太虚，回到第 4 步写具体一点。
