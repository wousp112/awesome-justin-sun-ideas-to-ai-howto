# 06 让机器来验证

> 「任何人就是用 AI 你去尽量去破解这个数学题，只要通过 Lean 的形式验证，就都可以获得孙宇晨奖。只要机器阅读、机器同意，就可以发奖。」
> —— 孙宇晨 [00:30:11](https://www.youtube.com/watch?v=o9Jn__LGGI4&t=1811s)

Lean 是一种能让电脑检查数学证明的语言。证明写成 Lean，电脑一步一步核对，通过了就说明推理没有漏洞，不用靠评委一行行看。孙宇晨奖就用这个规则，先公布一批数学题，证明写成 Lean 交给机器验，验过了就能领奖。

这一篇不需要你懂高深的数学，只是带你体验一次让 AI 写证明、让机器来验的过程。

## 怎么做

1. 打开 Lean 的在线编辑器，不用装软件就能试。
2. 玩一会儿自然数游戏，用 Lean 一关关证明加法的基本性质，感受一下它是怎么检查的。
3. 想正式用，就在电脑上装 Lean 和 VS Code 的 Lean 插件，这一步可以交给 AI。
4. 挑一个你懂的简单结论，比如两个偶数相加还是偶数，让 AI 写成 Lean 证明。
5. 把证明放进编辑器跑一遍。报错就把错误信息贴回给 AI，让它改，改到通过为止。
6. 想挑战更难的题，可以去看孙宇晨奖公布的题目，再到 Mathlib 里找有没有现成的定理能用。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |

| 在线写 Lean | [Lean 4 Web](https://live.lean-lang.org) | 同左 |

## 让 AI 帮你搭

```
帮我在电脑上装好 Lean，再跑通第一个证明。
1. 按 Lean 官网的方法装好 elan 和 Lean 4，再装 VS Code 的 lean4 插件。装完告诉我怎么确认装好了。
2. 新建一个 Lean 项目 lean实验/。
3. 把「两个偶数相加还是偶数」写成 Lean 证明，放进项目里编译。
4. 编译报错就自己读错误信息去改，直到通过。
5. 最后用大白话给我讲一遍，证明的每一步在干什么。
```
