# 06 让机器来验证

> 「任何人就是用 AI 你去尽量去破解这个数学题，只要通过 Lean 的形式验证，就都可以获得孙宇晨奖。只要机器阅读、机器同意，就可以发奖。」
>
> 孙宇晨，[00:30:11](https://www.youtube.com/watch?v=o9Jn__LGGI4&t=1811s)

Lean 是一种能让电脑检查数学证明的语言。证明写成 Lean，电脑一步一步核对，通过了就说明推理没有漏洞，不用靠评委一行行看。孙宇晨奖就用这个规则，先公布一批数学题，证明写成 Lean 交给机器验，机器验证通过才算数。题目和怎么提交，以奖项公布的说明为准。

跟着做不需要懂高深的数学，就是体验一次让 AI 写证明、再让机器来验的过程。

## 做完是这样

示例要证的是「两个偶数相加还是偶数」。AI 写的证明，每一步都配了中文注释：

```lean
-- 偶数的意思：能找到一个自然数 b，让 a = 2 * b。
def IsEven (a : Nat) := ∃ b, a = 2 * b

-- 如果 a、b 都是偶数，那么 a + b 也是偶数。
theorem even_plus_even (a b : Nat) (h1 : IsEven a) (h2 : IsEven b) :
    IsEven (a + b) :=
  -- 从 a 是偶数中取出 w1，以及等式 a = 2 * w1。
  Exists.elim h1 (fun w1 (hw1 : a = 2 * w1) =>
  -- 从 b 是偶数中取出 w2，以及等式 b = 2 * w2。
  Exists.elim h2 (fun w2 (hw2 : b = 2 * w2) =>
  -- 选 w1 + w2 作为 a + b 的一半，接下来证明它成立。
  Exists.intro (w1 + w2)
    (calc
      a + b = 2 * w1 + 2 * w2 := by rw [hw1, hw2]
      _ = 2 * (w1 + w2) := by rw [Nat.mul_add])))

#print axioms even_plus_even
```

交给 Lean 4.35.0 检查，没有报错，最后一行输出：

```
'even_plus_even' does not depend on any axioms
```

## 让 AI 帮你搭

```
帮我在电脑上装好 Lean，再跑通第一个证明。
1. 按 Lean 官网的方法装好 elan 和 Lean 4，再装 VS Code 的 lean4 插件。装完告诉我怎么确认装好了。
2. 新建一个 Lean 项目 lean实验/。
3. 把「两个偶数相加还是偶数」写成 Lean 证明，放进项目里编译。
4. 编译报错就自己读错误信息去改，直到通过。
5. 最后用大白话给我讲一遍，证明的每一步在干什么。
```

## 一步步来

1. 打开 Lean 的在线编辑器，不用装软件就能试。
2. 玩一会儿自然数游戏，用 Lean 一关关证明加法的基本性质，感受一下它是怎么检查的。
3. 想正式用，就在电脑上装 Lean 和 VS Code 的 Lean 插件，这一步可以交给 AI。
4. 挑一个你懂的简单结论，比如两个偶数相加还是偶数，让 AI 写成 Lean 证明。
5. 把编辑器里原来的内容删掉，粘贴 AI 给的证明，它会自动检查，不用点运行。报错就把错误信息贴回给 AI，让它改。右边没有红色报错，也没有 sorry 的提示，证明就通过了。
6. 想挑战更难的题，可以去看孙宇晨奖公布的题目，再到 Mathlib 里找有没有现成的定理能用。
