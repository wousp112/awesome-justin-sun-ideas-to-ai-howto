# 0.1 先装一个能动你电脑的 AI

后面每篇教程里都有一段写给 AI 的话，复制给它，它就能替你建文件夹、读文件、写文件。这需要一个能读写你电脑文件的 AI，一般叫 Agent。豆包、ChatGPT 网页版这类聊天 AI 碰不到你电脑里的文件，只能聊，做不了这些事。

## 选哪个

| 路线 | 选它 | 要准备什么 |
| --- | --- | --- |
| 推荐 | [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview) 或 [Codex](https://developers.openai.com/codex/cli) | Claude 或 ChatGPT 的付费账号，两家官方都不支持中国大陆 |
| 国内直接用 | [Kimi Code](https://www.kimi.com/help/kimi-code/membership-guide) 或 [Qwen Code](https://qwen.ai/qwencode) | 国内手机号就能开，Kimi 要开含编程的会员，Qwen 接阿里云百炼 |

每个工具多少钱、国内能不能直接用，都记在[工具总表](../../工具总表.md)里。孙宇晨在访谈里也说，用不起贵的就先用便宜的，先把流程 AI 化再说。

## 怎么装（以 Mac 为例）

1. 按 `Command + 空格`，输入「终端」，回车。
2. 打开上表里你选的工具的官网，找写着「安装」或 Install 的地方，那里有一行命令，复制下来。
3. 把命令粘贴到终端，回车，等它跑完。
4. 在终端输入工具的名字回车，Claude Code 是 `claude`，Codex 是 `codex`，Kimi Code 和 Qwen Code 的名字官网安装页会写。然后按提示登录。
5. 看到它等你输入要做的事，就装好了。

Windows 的话，按 `Win` 键搜「PowerShell」打开，后面一样，官网会给 Windows 的安装命令。

## 试一下

装好以后，把这句话发给它。

```
在我的桌面新建一个文件夹叫 AI实验室，在里面写一个 README.md，内容是今天的日期和一句「我开始了」。
```

打开桌面看一眼。有 `AI实验室` 这个文件夹，里面的 `README.md` 写着今天的日期和「我开始了」，说明它能读写你的电脑，后面的教程都能照着做。没有的话，看下面的「卡住了怎么办」。

## 卡住了怎么办

- 安装或登录报错，就把终端里的报错整段复制，发给豆包、Kimi 这类网页 AI，问它怎么办。官网打不开或者登录不上，一般是网络的问题，可以先换国内那条路线。
- AI 说找不到文件夹，就把那个文件夹拖进终端窗口，终端会填上它的完整路径，把这串路径发给 AI。
- 手机上的照片和文件，用隔空投送，或者微信的「文件传输助手」传到电脑上，再放进教程说的文件夹。
- 关掉终端以后，AI 就不记得上次聊过什么了。所以教程里的提示词都会让它把规矩写进文件夹里的 `README.md`。下次新开对话，先跟它说「读一下这个文件夹的 README.md」。
- 教程里的 `.md` 文件就是普通的文本文件，用电脑自带的文本编辑、Obsidian 或者思源笔记都能打开。
