# 03 先升级操作系统

> 「第一个就是『孙学』，就是理论武装自己……『孙学』是一个大脑相当于升级，你操作系统总得换嘛。」
>
> 孙宇晨，[00:12:21](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=741s)

孙宇晨总结了三个理论，第一个就是「孙学」。他把对金钱、对财富自由、对万事万物的理解比作操作系统，隔一阵就要升级一次。

怎么升级，他没细说。我们的做法是把自己的看法写下来，找资料去对，碰到能推翻它的证据就改，改了留个记录。

## 做完是这样

示例的看法是编的：「只看 Apple Watch 的睡眠时长和深睡，就能知道睡得好不好。」AI 找了支持和反对的研究，最后记下了这条改主意：

```
## 挑错：哪些地方说得太满

- 深睡数字不是精确测量。一项 35 人的研究里，Series 8 估计的深睡
  平均比睡眠监测少 43 分钟。
- 数字看着正常，也不能排除睡眠问题。苹果说明睡眠呼吸暂停提醒
  不能代替医生诊断。

## 改主意记录

- 2026-10-31：旧看法是只看时长和深睡就能判断睡得好不好。新看法是
  用手表看作息和长期变化，同时留意自己的感受。具体分期和有没有
  睡眠障碍，不能只靠手表判断。
```

## 让 AI 帮你搭

```
帮我建一个判断库。
1. 在桌面建「判断库」，里面建 资料 和 判断 两个子文件夹。资料 里的原文不许改。
2. 问我一个我最近在想的问题，帮我写成 判断/【主题】.md，包括我的观点、依据、什么证据会让我改主意。
3. 联网找几份支持和几份反对的一手资料，原文保存到 资料/，每份写上来源链接和日期。
4. 只根据 资料/ 里的内容给我的判断挑错，每条都标出处。
5. 我改主意时，在判断文件底部追加一条记录：日期、旧看法、新看法、因为哪份资料。
```

## 一步步来

1. 新建一个文件夹，叫 `判断库`，里面建 `资料` 和 `判断` 两个子文件夹。
2. 挑一件你最近一直在想的事，在 `判断` 里新建一个文件，比如 `判断/要不要换工作.md`，写下三句话，我现在怎么看，我凭什么这么看，看到什么我会改主意。现成的表头在 [模板/判断.md](../../模板/判断.md)。
3. 让 AI 帮你找几份支持你的资料，再找几份反对你的，原文存进 `资料`。AI 只给了链接、或者链接打不开的，不算数，让它换一份。
4. 让 AI 只根据 `资料` 里的东西，给你的看法挑错。
5. 被说服了就改，旧的不要删，在下面写上改了什么、因为哪份资料。
6. 一个问题想清楚了，再开下一个。
