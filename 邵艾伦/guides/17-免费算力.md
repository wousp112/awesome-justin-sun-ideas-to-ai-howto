# 1.17 免费算力

> 「但是我觉得可以装一个智谱啊，Kimi Code 啊，Z Code 这些，应该都是免费的。」
>
> 孙宇晨，[00:09:35](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=575s)

上一节讲怎么用更少的钱买会员。这一节讲另一头，把不要钱的算力先用起来。

Google 有一个叫 Colab 的东西，浏览器打开就能写 Python、跑任务，免费档还给显卡。你手上那些一次性的活，转录音、批量改图、爬一批网页、跑个小模型，都可以扔给它，不用在本机装环境，也不用买显卡。

## 做完是这样

我把一批录音丢给 Colab 跑转录，用的是开源的 whisper。整批跑完用了十几分钟，结果自动存回 Google Drive 的文件夹，文件名按录音名对齐。

本机什么都没装。合上电脑去吃饭，回来文件已经在 Drive 里了。

免费档的显卡不是每次都有，排队的时候会分到 CPU。这一点提前知道，就不会以为是代码写错了。

## 让 AI 帮你搭

```
我要在 Google Colab 里跑一个任务，任务是把【写在这里】。
1. 给我一个完整的 notebook，分单元格写，依赖装在第一个单元格。
2. 挂载 Google Drive，输入放在【路径】，输出存到【路径】。
3. 每一步告诉我怎么确认它跑成功了。
4. 把可能出错的地方写出来，出错该怎么改。
5. 最后告诉我，免费的显卡够不够跑这个任务，不够的话要先做什么调整。
```

## 一步步来

1. 用 Google 账号打开 colab.research.google.com，新建一个笔记本。
2. 先只跑一行，看看有没有分到显卡，菜单里能看到当前运行环境。
3. 确认环境没问题，再装依赖。装依赖那格跑完，会看到一行安装成功的提示。
4. 挂载 Drive，第一次会弹授权，同意之后左侧能看到你的云盘目录。
5. 用一个小文件先试跑，确认输出路径写对了，再换成整批文件。
6. 整批跑的时候别关浏览器标签，免费档空闲一段时间会断。
7. 跑完去 Drive 里核对文件数和文件名，数量对不上就看看日志里哪一条失败了。

## 要注意的

免费档会断。长时间不操作、跑得特别久、或者资源紧张，都可能被收回，重连之后要重新跑。

显卡不保证。同一天不同时段分到的东西不一样，代码要先在本机或者用 CPU 模式跑通，再上显卡。

别在 Colab 上跑长期服务。它适合跑一次就结束的任务，不适合挂个机器人一直在那。

付费档能提高额度和优先级，具体给多少以官网为准，我不在这里写死数字。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 写和跑脚本 | [Google Colab](https://colab.research.google.com) | 不能，要 Google 账号和能打开的网 |
| 存输入和输出 | [Google Drive](https://drive.google.com) | 不能，同上 |
| 本机先跑通再上云 | [Python](https://www.python.org/downloads/) 加 [uv](https://docs.astral.sh/uv/) | 能，官网直接下 |
| 转录这类现成任务 | [whisper](https://github.com/openai/whisper) | 能，代码开源，装在本机也行 |
