# 1.17 免费算力

> 「但是我觉得可以装一个智谱啊，Kimi Code 啊，Z Code 这些，应该都是免费的。」
>
> 孙宇晨，[00:09:35](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=575s)

孙宇晨说的是 Claude Code 太贵，就先装免费的 AI 编程工具。这一节是我们配的另一种用法，跑任务的机器也先找不要钱的。

Google 有一个叫 Colab 的东西，浏览器打开就能写 Python、跑任务，免费档还给显卡。你手上那些一次性的活都可以扔给它，比如转录一批录音、批量改图。爬一批网页、跑个小模型也行，不用买显卡。

## 做完是这样

拿转录一批录音来说，跑完以后 Google Drive 的输出文件夹里，每个录音都有一份同名的文字稿，比如 `会议-1103.m4a` 对应 `会议-1103.txt`。笔记本最后一格打印出转了几个、跳过了几个、哪几个失败了。

本机不用装 Python，也不用装显卡驱动。中途断了就重跑那一格，转好的会跳过，从断的地方接着转。

免费档的显卡不是每次都有，分不到的时候会提示连不上 GPU，只能先用 CPU 跑。这一点提前知道，就不会以为是代码写错了。

## 让 AI 帮你搭

```
我要在 Google Colab 里跑一个任务，任务是【写在这里】。
1. 给我一个完整的 notebook，分单元格写，依赖装在第一个单元格。
2. 挂载 Google Drive，输入放在【路径】，输出存到【路径】。路径按挂载后的 /content/drive/MyDrive/ 开头写。
3. 已经生成的输出文件跳过不处理，断线重跑时能接着往下跑。
4. 每一步告诉我怎么确认它跑成功了。
5. 把可能出错的地方写出来，出错该怎么改。
6. 最后告诉我，免费的显卡够不够跑这个任务，不够的话要先做什么调整。
```

## 一步步来

1. 先把要处理的文件传到 Google Drive 的一个文件夹里。
2. 用 Google 账号打开 [Google Colab](https://colab.research.google.com)，新建一个笔记本。
3. 新建的笔记本默认只有 CPU。在顶部菜单「代码执行程序」里点「更改运行时类型」，硬件加速器选 GPU，保存。
4. 在第一格输入 `!nvidia-smi`，点左边的运行键，能看到显卡型号就是分到了。提示连不上 GPU，就先用 CPU 往下做，或者换个时段再试。
5. 确认环境没问题，再装依赖。命令前面要加感叹号，比如 `!pip install`，跑完会看到一行安装成功的提示。
6. 挂载 Drive，第一次会弹授权，同意之后左侧能看到你的云盘目录。
7. 用一个小文件先试跑，确认输出路径写对了，再换成整批文件。
8. 整批跑的时候别关浏览器标签，免费档空闲一段时间会断。
9. 跑完去 Drive 里核对文件数和文件名，数量对不上就看看日志里哪一条失败了。

## 要注意的

免费档会断。官方说免费档一次最长跑 12 小时，长时间不操作或者资源紧张也可能被收回。断了以后装过的依赖和没存进 Drive 的文件都会清空，重连要重新装、重新挂载。

显卡不保证。能不能连上、一次能用多久，看当时资源紧不紧。代码要先拿小文件用 CPU 跑通，再换显卡跑整批。

转录用 whisper 的 turbo 模型，它是 large-v3 的提速版，准确率差不多，要大约 6GB 显存，跑之前在 `!nvidia-smi` 的结果里看一眼显存够不够。中文录音加上 `--language Chinese`，免得它自己猜错语言。

只把跑完就停的任务放进 Colab，一直在线的机器人别放这里。

付费档能提高额度和优先级，具体给多少，官方自己也没有公开。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 写和跑脚本 | [Google Colab](https://colab.research.google.com) | [魔搭 Notebook](https://modelscope.cn)，有免费 GPU 时长 |
| 存输入和输出 | [Google Drive](https://drive.google.com) | 魔搭 Notebook 自带的存储 |
| 想在本机跑同一个脚本 | [Python](https://www.python.org/downloads/) 加 [uv](https://docs.astral.sh/uv/) | 同左 |
| 转录这类现成任务 | [whisper](https://github.com/openai/whisper) | 同左 |
