# 15 多创造，少消费

> 「人类也分两种活动，一种创造活动，一种消费活动，对吧？……这个我觉得大面上是创造活动啊。」
>
> 孙宇晨，[04:12:27](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=15147s)
>
> 「多创造，少消费，然后你做什么基本上都是对的。」
>
> 邵艾伦，[04:13:08](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=15188s)

访谈快结束的时候，两个人聊到这一条。「多创造，少消费」是邵艾伦的总结，孙宇晨接着说「我觉得是以创造为主吧」（[04:15:52](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=15352s)）。他也说消费不用全戒掉，它能帮你回血，但大部分时间还是放在创造上。

现在有了 AI，做东西容易了很多。你刚搞懂的东西，自己说一遍经过，AI 能帮你整理成别人照着就能用的教程、清单或者小工具，你再发出去。

## 做完是这样

示例里的经历是编的。AI 帮着写成了一篇能发的教程，开头是这样：

```
# 写方案时手机总亮？我用 iPhone 这样留住微信，安静其他通知

做运营的时候，我经常一边写方案，一边被手机提醒打断。微信工作群得看，
其他通知又会让我忍不住点开。

## 先建一个“写方案”模式

1. 打开 iPhone 的「设置」，点「专注模式」。
2. 点右上角的「＋」，再点「自定义」。
3. 输入名称「写方案」，选一个颜色和图标，点「下一步」。
```

发之前把经历和截图换成自己的。

## 让 AI 帮你搭

```
帮我开始做作品。
1. 先问我最近解决了什么问题、擅长什么、想发在哪个平台。
2. 根据我的回答，列出几个现在就能做的作品选题，每个写清楚是什么、给谁用、要准备什么。
3. 在桌面建「作品」文件夹，每个作品一个子文件夹，放草稿和最终版。
4. 现在就帮我开始第一个：先让我口述经历，你整理成新手教程，步骤具体到点哪里、输入什么。保持我的说话风格，不要写成官方腔。
```

## 一步步来

1. 想一个你最近刚解决的问题，比如装好了某个工具，搞懂了某个概念。
2. 跟 Agent 说「我刚搞定了【这件事】，帮我写成一篇新手教程，步骤要具体到点哪个按钮」。
3. 自己读一遍，把不像你会说的话改掉。步骤要一条条对一遍，你没做过的删掉，按钮名字跟你屏幕上看到的对上。然后发在你常用的平台，公众号、小红书、GitHub 都行。
4. 下一个可以换个形式，一份清单，一个模板，一段好用的 prompt（发给 AI 的那段话），或者一个小工具。
5. 发出去的东西攒多了，可以整理成一个合集页，一篇置顶文章列出你发过的所有东西就行。
6. 有个小办法可以试试，先做一会儿东西，再去刷信息流。

这个仓库就是这么来的，两期访谈，我们做成了全文、教程和一份给 AI 的说明。
