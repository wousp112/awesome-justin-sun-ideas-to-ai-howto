# 09 机器读得懂才值钱

> 「AI 只能读得懂机器读得懂的东西。」
>
> 孙宇晨，[01:33:10](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=5590s)
>
> 「你必须把它形式化了……让计算机读懂了，才算是消化。」
>
> 孙宇晨，[01:37:22](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=5842s)

孙宇晨聊到数学、天文、历史资料的时候，反复讲一件事，没被 AI 读到的东西，在 AI 时代就像不存在。

放到你自己身上，就是电脑里那些扫描件、截图、乱七八糟的表格。AI 读不了它们，也就帮不上你。先把你最常用的几份资料转成 AI 能读的 Markdown，后面好几篇教程都会用到这些文件。Markdown 是一种纯文本格式，文件名以 `.md` 结尾，记事本就能打开，AI 读起来也最省事。

## 做完是这样

示例里有一份编的 txt 随手记。转完以后，开头记下了出处，正文 AI 能直接读：

```
原文件名：五天运营随手记.txt
转换日期：2026-10-31

五天运营随手记

10月26日 周一
上午整理了小红书上周的评论，大家最常问的是活动什么时候结束。
午饭后和设计同事对了一版封面，晚上回家用 MacBook 把文案改完。

10月27日 周二
早上坐地铁时看了微信工作群，活动页面有一处按钮文案不太清楚。
下午跟产品同事确认，把“立即参与”改成“查看活动”。
```

## 让 AI 帮你搭

```
帮我把旧资料变成 AI 能读的文件。
1. 在桌面建「资料库」文件夹，里面建 原件 和 可读版 两个子文件夹。原件里的文件永远不许修改。
2. 检查我电脑有没有 Python，没有就帮我装。然后安装 MarkItDown（pip install 'markitdown[all]'）。安装时要密码或者报错，停下来把报错原文给我看。
3. 把 原件 里每个文件转成 Markdown，放进 可读版。每个文件开头写上原文件名、转换日期、用的工具。
4. 如果是扫描件或中文复杂 PDF，MarkItDown 转出来是乱码，就改用 MinerU 或 OCRmyPDF，装之前先告诉我。
5. 每份文件随机抽 3 个数字或专有名词和原件核对，把核对结果列给我。
6. 在 资料库 写一个 README.md，一行一份资料，说明它讲什么。
```

## 一步步来

1. 在桌面新建一个文件夹，叫 `资料库`，里面建 `原件` 和 `可读版` 两个子文件夹。
2. 挑一份你最常用的 PDF，复制进 `原件`。原件只放，不改。
3. 跟你的 Agent 说「把 `资料库/原件` 里的 PDF 转成 Markdown，放进 `可读版`」。
4. 用 Obsidian、思源笔记或者电脑自带的文本编辑，打开转出来的 `.md` 文件，跟原件并排放，随便挑几个数字和人名对一对。
5. 对得上，就把其他常用资料也放进去，让 AI 一起转。每个文件开头写上来源文件名、日期、用的什么工具。
6. 哪一份错得多，就换个工具重新转。扫描件和中文复杂 PDF 一般要用下面表里专门的工具。
7. 最后让 AI 在 `资料库` 里写一个 `README.md`，一行一份资料，写清楚它讲什么。以后哪个 AI 进来，先读这个就行。

## 用什么工具

| 资料类型 | 推荐 | 说明 |
| --- | --- | --- |
| 普通 PDF、Word、PPT、Excel | [MarkItDown](https://github.com/microsoft/markitdown) | 微软开源，免费，一行命令转换 |
| 中文复杂 PDF、公式、表格 | [MinerU](https://github.com/opendatalab/MinerU) | 国内团队开源，中文效果好 |
| 扫描版 PDF | [OCRmyPDF](https://github.com/ocrmypdf/OCRmyPDF) | 给扫描件加上能复制的文字层 |
| 乱七八糟的表格 | [OpenRefine](https://github.com/OpenRefine/OpenRefine) | 可视化清理重复值和格式错误 |
| 查看转换结果 | [Obsidian](https://obsidian.md) / [思源笔记](https://b3log.org/siyuan/) | 都免费 |

这几个都是免费开源的，在你自己电脑上跑，资料不用上传，国内外都能用。
