# 1.13 游戏版本会更新

> 「每个大版本地球也会更新。你这个版本就削弱房地产，你前面房地产强，后面削弱，AI 又加强啊。」
>
> 孙宇晨，[02:33:57](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=9237s)

孙宇晨拿打游戏打比方，上个版本最强的打法，换了版本可能就不灵了。AI 是这一版被加强的，他也说不准再过十年会不会被削弱。

版本什么时候变，谁也说不准，不过能比别人早一点察觉。你可以搭一个小雷达，只装少量一手信息源，让 AI 替你看哪里在变。雷达靠 RSS，就是把各个网站的更新收进一个阅读器里看，跟关注公众号差不多，只是不靠算法推荐。

## 做完是这样

示例关注的是 AI 怎么改变互联网运营的工作。这是 AI 读完一手来源后写的一期：

```
# 版本更新雷达｜2026-10-31

## 什么加强了
- 整理资料：ChatGPT Work 的 Data agent 能用提问的方式分析企业数据、
  做交互图表。（OpenAI，9 月 10 日）
- 跨工具工作：Gemini 开始接入 Airtable、Adobe 等工具。（Google，9 月 23 日）

## 我该开始做什么
- 拿一份不含公司数据的模拟活动表，让工具回答「哪个渠道值得继续看」，
  再对照原表核对数字。

## 我该停止做什么
- 看到新功能就马上换工具。先查自己的账号和地区支不支持。
```

## 让 AI 帮你搭

```
帮我搭一个版本更新雷达。
1. 问我在哪个行业、关心什么方向。
2. 帮我列出这个方向的几个版本信号，每个推荐 1-2 个一手信息源（官方博客、GitHub、公司公告），给出 RSS 地址。
3. 告诉我怎么在 Folo 里导入这些源。
4. 我把收藏的条目发给你，你就写一页 雷达/【日期】.md：什么加强了、什么削弱了、我该开始做什么、停止做什么。
```

## 一步步来

1. 想一想你这一行有哪些「版本信号」，比如招聘多了还是少了，头部公司发了什么，有什么新政策，客户预算怎么变，开源项目活不活跃。
2. 每个信号找一两个一手来源，官方博客、公司公告、GitHub 仓库都算。
3. 全部订阅进一个 RSS 阅读器。找不到订阅地址的来源，让 AI 帮你查，或者用阅读器自带的搜索。
4. 过几天打开阅读器看看。哪个来源一直是空的，八成是订阅地址填错了，换一个。
5. 有空就翻一翻，觉得有意思的收藏起来。
6. 收藏攒到一定数量，丢给 AI，让它写一页「版本更新」，什么变强了，什么变弱了，你手上哪件事该停了。

新工具出来，可以先拿一件小事试试，好用再搬，不用看到热度就全换。
