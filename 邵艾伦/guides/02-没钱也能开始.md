# 02 没钱也能开始

> 「我觉得多少钱都可以做，先把你的这个整套流程全部 AI 化。」
>
> 孙宇晨，[00:10:30](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=630s)

孙宇晨说 Claude Code 太贵，一个月就要 200 美元，很多人用不起。最便宜的档位比这低，具体看[工具总表](../../工具总表.md)。他的意思是先找便宜的用着，智谱、Kimi Code 这些都行，先把流程 AI 化。

所以这一篇从一件你经常要做、又挺烦的事入手，用免费或便宜的 AI 把它接过去。做顺了，再考虑要不要花钱升级。

## 怎么做

1. 想一件你经常重复做、每次都要花一阵子的事，比如整理会议记录、回同一类邮件、做周报。
2. 把你平时是怎么做的，用几句话写下来。
3. 打开任何一个免费的 AI，把这几句话和一份真实材料发给它，说「按这个流程帮我做一次」。
4. 结果不对，就回去改那几句话，再试。改了两三次还不对，多半是少给了材料，把一份你以前做好的成品也发给它对照。
5. 结果能用了，在电脑上建一个 `流程` 文件夹，把这几句话存成 `流程/【事情名】.md`，下次直接复制给 AI。
6. 用了一段时间，算算省了多少时间、花了多少钱。觉得不值，停掉就行。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |

孙宇晨在访谈里点名的有智谱（GLM）和 Kimi Code。

## 让 AI 帮你搭

```
我想用最少的钱把一件重复的事交给 AI。
1. 先问我哪件事最烦、我平时怎么做的，再要一份真实样本。
2. 把我的做法写成流程文件，存到 流程/【事情名】.md，写清楚输入是什么、输出是什么、怎么检查对不对。
3. 用这个流程处理我给的样本，让我检查。
4. 以后我说「跑一下【事情名】」，你就按流程文件执行。
5. 每次执行完在 流程/记录.md 里记一行：日期、花了几分钟、有没有出错。
6. 把上面这些规矩写进 流程/README.md。以后我新开对话，会先让你读这个文件。
```
