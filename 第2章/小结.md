# 2.7 小结

### 重点回顾

- 「孙学」是给自己的认知换操作系统。把看法写下来，找资料去对，碰到能推翻它的证据就改，改了留记录。
- 他拿 AI 的 skill 比喻孙学，装上就能用。你认同的方法、你自己做事的方法，也能蒸馏成一个 skill。
- Small ego 就是愿意照着证据改主意。让 AI 站到反对者那边，专门挑你的错。
- 游戏版本会更新，这一版加强的是 AI。装几个一手信息源，让 AI 替你看哪里在变。
- 缺什么就去补第一视角。按目标岗位的真实格式做一份交付物，请干这行的人帮你改。
- 老登资产他都不看好，新登资产积极拥抱。钱、技能、工具和每天看的信息都可以盘一遍，找出哪些在变旧。

### Q & A

#### Q：做好的 skill 怎么给别人用？

放到 GitHub 上，别人用 `npx skills add 你的用户名/仓库名` 一行命令就能装。这个仓库就是这么做的，见[装进 Agent](../前言.md#装进-agent)。
